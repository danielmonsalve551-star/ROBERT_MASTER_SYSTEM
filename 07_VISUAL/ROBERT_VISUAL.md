# OBJETIVO

Definir la dirección visual inicial de Robert.

Este documento existe para ordenar cómo debe verse Robert como sistema visual, sin confundir diseño con arquitectura.

ROBERT_VISUAL_REFERENCE debe ayudar a definir:

- estilo visual;
    
- interfaz principal;
    
- núcleo central;
    
- módulos visibles;
    
- paneles;
    
- colores;
    
- jerarquía visual;
    
- comandos visibles;
    
- estados del sistema;
    
- autonomía controlada;
    
- apps conectadas;
    
- experiencia de usuario;
    
- referencias visuales aprobadas o descartadas.
    

Este documento no define cómo funciona Robert por dentro.

La arquitectura interna vive en:

- ROBERT_SYSTEM_ARCHITECTURE;
    
- ROBERT_SECURITY_RULES;
    
- ROBERT_COMMANDS;
    
- ROBERT_CONTEXT_MASTER;
    
- ROBERT_MODULES.
    

La visualización debe representar el sistema.

No debe inventarlo.

# NÚCLEO CENTRAL

El núcleo central representa a Robert Core.

Debe mostrar que Robert conecta:

- contexto;
    
- memoria;
    
- documentos;
    
- comandos;
    
- decisiones;
    
- módulos;
    
- seguridad;
    
- arquitectura;
    
- apps;
    
- autonomía;
    
- visualización.
    

El núcleo puede cambiar de estado visual según lo que esté ocurriendo.

Estados posibles:

1. Reposo  
    Robert está esperando instrucciones.
    
2. Escucha  
    Robert está recibiendo input.
    
3. Análisis  
    Robert está interpretando información.
    
4. Clasificación  
    Robert está decidiendo dónde va la información.
    
5. Borrador  
    Robert está preparando texto, documento o estructura.
    
6. Autorización pendiente  
    Robert necesita permiso del usuario.
    
7. Bloqueo de seguridad  
    Robert detectó una acción no permitida.
    
8. Autonomía activa  
    Robert está trabajando dentro de un alcance autorizado.
    
9. Sandbox  
    Robert está probando sin afectar sistemas reales.
    
10. Ejecución limitada  
    Robert está realizando una acción permitida dentro de límites.
    

Regla:

El núcleo debe comunicar estado.

No debe ser solo decorativo.
